### Extending the candle store

This script never syncs. To add candles, run (writes into the shared data folder):

```
cd /Users/mike/code/crypto-moonshot && uv run moonshot data sync --data-dir /Users/mike/code/crypto-moonshot/data --start 2026-10-01 --progress none $(uv run --group research python research/rebound_factors/forward.py --list-sync-symbols)
```

then rerun `uv run --group research python forward.py` from `research/rebound_factors/`. The symbols are `paper.py`'s `listed_symbols` (391 now): `top200.txt` minus pegged assets and tokenised stocks, plus `outside_pool.txt`, BTCUSDT and ETHUSDT. Delisted coins cannot gain new candles; a coin listed after those lists were made appears only after it is added to `top200.txt` or `outside_pool.txt` and synced. A coin missing from the store is simply not an entry.
